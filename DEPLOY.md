# Инструкция по деплою на Beget

## Подготовка проекта

1. **Соберите проект локально:**
   ```bash
   npm install
   npm run build
   ```

2. **Проверьте, что все файлы скомпилированы:**
   - Убедитесь, что папка `dist/` содержит все скомпилированные файлы
   - Проверьте, что `server.js` находится в корне проекта

## Загрузка на Beget

1. **Подключитесь к серверу Beget по SSH:**
   ```bash
   ssh username@your-domain.beget.tech
   ```

2. **Создайте директорию для проекта:**
   ```bash
   mkdir -p ~/chainz
   cd ~/chainz
   ```

3. **Загрузите файлы проекта:**
   - Используйте FTP/SFTP клиент (FileZilla, WinSCP) или `scp`
   - Загрузите все файлы проекта, кроме:
     - `node_modules/` (будет установлен на сервере)
     - `.env` (создадите на сервере)
     - `dist/` (будет создан при сборке)

4. **Или используйте Git (рекомендуется):**
   ```bash
   git clone your-repository-url .
   ```

## Настройка на сервере

1. **Установите зависимости:**
   ```bash
   npm install --production
   ```

2. **Создайте файл `.env`:**
   ```bash
   cp .env.example .env
   nano .env
   ```
   
   Заполните переменные окружения:
   ```env
   BOT_TOKEN=ваш_токен_бота
   DATABASE_URL=postgresql://username:password@localhost:5432/chainz
   ADMIN_PASSWORD=ваш_безопасный_пароль
   ADMIN_PORT=3000
   NODE_ENV=production
   ```

3. **Настройте базу данных PostgreSQL:**
   - В панели управления Beget создайте базу данных PostgreSQL
   - Запишите данные подключения (host, port, username, password, database name)
   - Обновите `DATABASE_URL` в `.env` файле

4. **Запустите миграции:**
   ```bash
   npm run migrate
   ```

## Настройка Node.js приложения в панели Beget

1. **Войдите в панель управления Beget**

2. **Перейдите в раздел "Node.js приложения"**

3. **Создайте новое приложение:**
   - **Путь к приложению:** `/home/u/username/chainz` (замените username на ваш)
   - **Файл запуска:** `server.js`
   - **Порт:** `3000` (или другой, указанный в переменной окружения PORT)
   - **Версия Node.js:** `18.x` или `20.x` (проверьте доступные версии)

4. **Настройте переменные окружения:**
   - В настройках приложения добавьте переменные из `.env` файла:
     - `BOT_TOKEN`
     - `DATABASE_URL`
     - `ADMIN_PASSWORD`
     - `NODE_ENV=production`
     - `PORT=3000`

5. **Запустите приложение:**
   - Нажмите кнопку "Запустить" или "Перезапустить"
   - Проверьте логи на наличие ошибок

## Проверка работы

1. **Проверьте бота:**
   - Откройте Telegram и найдите вашего бота
   - Отправьте команду `/start`
   - Бот должен ответить

2. **Проверьте админ-панель:**
   - Откройте в браузере: `https://your-domain.com/admin`
   - Введите пароль из `ADMIN_PASSWORD`
   - Должна открыться админ-панель

3. **Проверьте API:**
   - Откройте: `https://your-domain.com/api/stats`
   - Должен запросить авторизацию (Basic Auth)

## Мониторинг и логи

1. **Просмотр логов в панели Beget:**
   - Перейдите в раздел "Node.js приложения"
   - Выберите ваше приложение
   - Откройте вкладку "Логи"

2. **Просмотр логов через SSH:**
   ```bash
   tail -f ~/chainz/logs/app.log
   # или
   pm2 logs chainz
   ```

## Обновление приложения

1. **Остановите приложение в панели Beget**

2. **Обновите код:**
   ```bash
   cd ~/chainz
   git pull  # если используете Git
   # или загрузите новые файлы через FTP
   ```

3. **Установите зависимости (если изменились):**
   ```bash
   npm install --production
   ```

4. **Пересоберите проект:**
   ```bash
   npm run build
   ```

5. **Запустите миграции (если есть новые):**
   ```bash
   npm run migrate
   ```

6. **Запустите приложение в панели Beget**

## Решение проблем

### Бот не отвечает
- Проверьте, что `BOT_TOKEN` правильный
- Проверьте логи приложения
- Убедитесь, что приложение запущено

### Ошибка подключения к базе данных
- Проверьте `DATABASE_URL` в `.env`
- Убедитесь, что база данных создана
- Проверьте права доступа пользователя базы данных

### Ошибка "Cannot find module"
- Убедитесь, что выполнили `npm install`
- Проверьте, что проект собран: `npm run build`
- Проверьте пути к модулям в `server.js`

### Порт занят
- Измените `PORT` в `.env` на другой порт
- Обновите настройки приложения в панели Beget

## Дополнительные настройки

### Использование PM2 (опционально)
Если Beget поддерживает PM2, можно использовать его для управления процессом:

```bash
npm install -g pm2
pm2 start server.js --name chainz
pm2 save
pm2 startup
```

### Настройка домена
1. В панели Beget настройте поддомен или основной домен
2. Настройте проксирование на порт вашего Node.js приложения
3. Обновите `.htaccess` если нужно

## Безопасность

1. **Не загружайте `.env` файл в Git:**
   - Убедитесь, что `.env` в `.gitignore`
   - Используйте `.env.example` для примера

2. **Используйте сильный пароль для админ-панели:**
   - Измените `ADMIN_PASSWORD` на сложный пароль

3. **Ограничьте доступ к админ-панели:**
   - Рассмотрите возможность добавления IP-фильтрации в `.htaccess`

4. **Регулярно обновляйте зависимости:**
   ```bash
   npm audit
   npm audit fix
   ```

## Контакты и поддержка

При возникновении проблем:
1. Проверьте логи приложения
2. Проверьте документацию Beget
3. Обратитесь в поддержку Beget
