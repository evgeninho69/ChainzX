# Чеклист для деплоя на Beget

## Перед загрузкой на сервер

- [ ] Проект собран локально (`npm run build`)
- [ ] Папка `dist/` содержит все скомпилированные файлы
- [ ] Файл `server.js` находится в корне проекта
- [ ] Файл `.env.example` содержит примеры всех переменных
- [ ] Все зависимости указаны в `package.json`
- [ ] `.gitignore` настроен правильно

## На сервере Beget

### Настройка окружения
- [ ] Создана база данных PostgreSQL
- [ ] Создан файл `.env` с правильными значениями
- [ ] Переменные окружения установлены в панели Beget:
  - [ ] `BOT_TOKEN`
  - [ ] `DATABASE_URL`
  - [ ] `ADMIN_PASSWORD`
  - [ ] `NODE_ENV=production`
  - [ ] `PORT=3000`

### Установка зависимостей
- [ ] Выполнено `npm install --production`
- [ ] Выполнено `npm run build`
- [ ] Выполнено `npm run migrate:prod`

### Настройка Node.js приложения
- [ ] Создано Node.js приложение в панели Beget
- [ ] Указан правильный путь к проекту
- [ ] Указан файл запуска: `server.js`
- [ ] Указан порт: `3000`
- [ ] Выбрана версия Node.js: `18.x` или `20.x`
- [ ] Приложение запущено

## Проверка работы

- [ ] Бот отвечает на команду `/start` в Telegram
- [ ] Админ-панель доступна по адресу `/admin`
- [ ] API отвечает на запросы `/api/stats`
- [ ] Логи не содержат критических ошибок
- [ ] База данных подключена и работает

## После деплоя

- [ ] Настроен мониторинг логов
- [ ] Настроены уведомления об ошибках (если нужно)
- [ ] Создана резервная копия базы данных
- [ ] Документированы учетные данные для доступа

## Полезные команды

```bash
# Проверка статуса приложения
pm2 status  # если используется PM2

# Просмотр логов
tail -f ~/chainz/logs/app.log

# Перезапуск приложения
# Через панель Beget или:
pm2 restart chainz

# Проверка подключения к БД
psql $DATABASE_URL -c "SELECT NOW();"
```
